# M5 — Settings, appearance and shortcuts

**Goal:** Make the app configurable: the full Settings window from spec §3.6, the Liquid Glass look, widgets you can turn off and reorder, and global shortcuts. Plus the small debts earlier milestones deferred.

**Spec:** `docs/superpowers/specs/2026-09-19-sidenotch-design.md` §3.6 (Settings), §3.1/§5 (appearance, Reduce Motion), §4.2, §4.8 (shortcuts). Architecture: `docs/architecture.md`.

## Constraints
The usual: Swift 6, macOS 26 floor (27-only APIs only behind `if #available`), no polling, Swift Testing, app name only in `Config/Branding.xcconfig`, features never import `NotchKit` or each other, commits end with the `Co-Authored-By` trailer. Test-first for logic; views hand-checked.

## Phase 1 — Widget identity and ordering
- Replace the `WidgetID` **enum** with a string-backed `struct WidgetID: RawRepresentable, Hashable, Codable, Sendable` plus static constants (`.shelf`, `.notes`, `.reminders`). Raw values stay `"shelf"`, `"notes"`, `"reminders"`, so saved data keeps working. A new widget then needs no edit to shared code (`docs/adding-a-widget.md` gets a matching update).
- `NotchController` must ignore a `.shortcut(id)` for a widget it doesn't hold, and build its size table with `uniquingKeysWith:` so duplicate ids can't trap (deferred from M1).
- `Preferences` gains `enabledWidgetIDs: [WidgetID]` (order matters; unknown ids ignored, new widgets appended at the end). The notch shows exactly those, in that order, and reacts live when the list changes.

## Phase 2 — Settings window
Tabs, each a small view in `SettingsFeature`:
- **General:** edge, display, reset position, launch at login (exists), plus *hide the pill under full-screen apps* (`hidesInFullScreen`, default off).
- **Appearance:** style **Solid black** (default) / **Liquid Glass**; pill size **S / M / L**; accent colour; hover delay (0.05–0.5 s); "Reduce motion" override (System / Always / Never).
- **Widgets:** a list with a checkbox per widget and drag-to-reorder. Use the macOS 27 reorder API when available, `.onMove` otherwise.
- **Shelf:** item count and *Clear shelf*.
- **Notes:** note count and *Export all notes…* (a folder picker, one `.md` per note, names taken from the title, deduplicated).
- **Reminders:** snooze length (5/10/15/30 min) and the two custom chip times (the "Tonight" and "Tomorrow" hours).
- **Shortcuts:** record a global shortcut for each widget and for toggling the notch; each row shows the current shortcut, a record button and a clear button; conflicts inside the app are rejected with a message.
- **About:** app name, version, build, a link to the repository.

The Settings window stops holding the app active once it closes (deferred from M1): return the activation policy after close so the notch's full-screen detection isn't skewed.

## Phase 3 — Appearance and motion
- `DesignSystem` gains a `NotchSurface` style: solid black, or Liquid Glass (macOS 26+ glass material behind the shape, with the pill staying black-edged so it still reads as part of the bezel).
- Pill size S/M/L scales `NotchMetrics` (folded depth/length and the tiles column), leaving the hover rules unchanged.
- Accent colour flows through `Palette`.
- Reduce Motion, when on, also disables the tiles/expanded content transitions, not just the shape spring (deferred from M1).
- Re-evaluate full-screen ghosting when the screen or display preference changes (deferred from M1).

## Phase 4 — Global shortcuts
- `ShortcutCenter` in the app target: register/unregister with Carbon `RegisterEventHotKey` (works sandboxed, needs no Accessibility permission), one hot key per assigned shortcut, all torn down on change.
- A shortcut sends `NotchController.send(.shortcut(id))`; the toggle shortcut folds or opens the tiles.
- Persist shortcuts in `Preferences` as key code + modifier flags. Recording is a small `NSView`-backed recorder that captures the next key press.

## Tests (first, where logic exists)
- `WidgetID` round-trips through JSON with the same raw values as before; unknown ids decode.
- `Preferences`: enabled/ordered widget list persists; unknown ids are dropped; a newly registered widget appends; every new setting round-trips with sane defaults.
- Notes export: file names derive from titles, collisions get a numeric suffix, invalid path characters are replaced.
- Shortcut model: encode/decode; conflict detection rejects a duplicate assignment.
- `NotchMetrics` scaling: S/M/L produce the expected folded depth/length, and the hot-rect rules still hold.
- Controller: `.shortcut(id)` for an unregistered widget changes nothing (pure state-machine test).

## Done when
- `make test` passes, `make build` clean, no-polling grep prints `no polling`.
- Hand check (owner): turning a widget off removes its tile and turning it back on restores it in the chosen order; switching to Liquid Glass changes the look; S/M/L resizes the pill; a recorded shortcut opens that widget from any app; *Clear shelf* empties it; *Export all notes…* writes files; changing the snooze length changes what Snooze does.
