## Behaviour and tricky parts
1. **Bookmarks, never copies.** On drop, `makeBookmark(url)` creates a security-scoped bookmark (`.withSecurityScope`). Resolving one uses `.withSecurityScope`. If the bookmark is stale but still resolves, replace it with a fresh one and save. If it can't be resolved, the item is **Missing**: shown greyed out and only removable. Any file access goes through `startAccessingSecurityScopedResource` / `stop…`, using a scoped helper so every start is matched by a stop.
2. **Deduplicate** by the resolved standardized path, against existing items and within the same drop. `add` returns the number of items actually added. `handleFileDrop` returns `false` when that number is 0, and the container already re-syncs the pointer on a rejected drop.
3. **Dragging out always copies.** `FileDragSource` uses an AppKit `NSDraggingSource`, and its `sourceOperationMaskFor` returns `.copy` in every context. SwiftUI's `.onDrag` can't restrict the operation, which is why AppKit is needed here. When the session ends with any operation other than `[]`, call `store.consume(ids)` to remove those items. If the drag is cancelled, the items stay. Dragging a selected item drags every selected item as one multi-item session.
4. **Opening files.** A plain click calls `NSWorkspace.shared.open(url)` inside the security scope. ⌘-click toggles selection. Space shows Quick Look of the hovered item using SwiftUI `.quickLookPreview`; this needs the panel to be key, which it is after any click in the expanded shelf.
5. **Thumbnails** come from `QLThumbnailGenerator` and are loaded lazily per cell. The cache belongs to the expanded view, so it is freed on fold. A missing item shows a generic document icon.
6. **Persistence.** `shelf.json` is saved as `{ "version": 1, "items": [...] }`. `JSONFileStore`:
   - writes atomically on a background queue, debounced 0.5 s, and `flush()` writes synchronously;
   - renames a file it can't decode to `<name>.corrupt-<timestamp>.json` and starts empty, logging the error with `AppIdentity.logger("persistence")`;
   - on a write failure, logs and keeps the in-memory state.

   The store flushes when the app terminates.
7. **No polling.** Nothing here may use a timer, except that the debounce may use one cancellable `Task.sleep` per save burst.

## Tests (write them first)
- **JSONFileStore:**
  - a value written and loaded back comes out the same;
  - a missing file loads as `nil`;
  - a corrupt file is quarantined, returns `nil`, and the renamed file exists;
  - several `save`s followed by `flush()` write only the last value;
  - saving into a directory that doesn't exist creates it.
- **ShelfStore** (with a fake resolver, where a URL maps to bookmark data and back):
  - adding returns the number added;
  - duplicates are ignored, both across drops and within one drop;
  - `remove`, `clear` and `consume` work;
  - an item that can't be resolved counts as missing;
  - a stale item's bookmark is refreshed and saved;
  - the items survive a reload through `JSONFileStore` in a temporary directory;
  - order is newest first.

## Done when
- `make test` passes with no warnings, and `make build` is clean.
- The no-polling grep prints `no polling`.
- These hand checks pass (the owner does them):
  1. Drop 2 files and see thumbnails.
  2. Quit and relaunch: the files are still there.
  3. Click a file and it opens.
  4. Drag a file to the Desktop: it is copied (the original stays), and the item leaves the shelf.
  5. Drop the same file twice: it only appears once.
  6. Rename the original in Finder: the item still opens.
  7. Delete the original: the item shows "Missing".
